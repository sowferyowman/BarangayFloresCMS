# BarangayFloresCMS
The Barangay Flores Case Management System was developed as a React and TypeScript desktop-style application, built using the Vite build tool. The application runs as a self-contained frontend that stores all barangay case records locally within the device's browser storage (localStorage), which keeps the system lightweight, easy to package for offline use, and free of dependency on an external or cloud-hosted database. This design directly supports the barangay's requirement for a secure, offline-capable system that does not expose sensitive resident data to the internet.

Barangay Flores previously relied on handwritten blotter records and paper logbooks to document complaints, mediation proceedings, and case outcomes. The Barangay Flores Case Management System was built to address these gaps by digitizing case intake, case history logging, and reporting helping the barangay move toward an efficient, secure, and modernized approach to managing case records.
